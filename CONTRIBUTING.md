# Contributing

## Branches
- `main` — stable
- `develop` — integration
- `feature/*` — feature work
- `fix/*` — bug fixes
- `docs/*` — documentation

## Commits
Use Conventional Commit style:
```text
feat: add user registration
fix: handle duplicate email
test: add authentication coverage
docs: document authentication flow
refactor: extract user service
ci: add security scan
```

## Pull requests
Meaningful changes should explain the problem and solution, include tests when behavior changes, update relevant documentation and pass CI.
